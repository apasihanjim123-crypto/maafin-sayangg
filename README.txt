WEBSITE MAAFAN PACAR 💗

2. Buka folder maafin-pacar di VS Code.
3. Buka index.html, klik kanan > Open with Live Server (jika ekstensi Live Server tersedia), atau buka index.html langsung di browser.

Edit teks permintaan maaf di index.html sesuai kebutuhan.
